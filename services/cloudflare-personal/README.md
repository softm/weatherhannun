# 날씨한눈 개인화 전용 DB

공통 SNS 로그인은 기존 Cloudflare 공통 계정 서비스에서 처리한다. 날씨 예보 캐시 DB와 개인화 DB는 **절대 공유하지 않는다**.

- 신규 D1 이름: `weatherhannun-personal-db` (생성 전 제안 이름)
- 이 디렉터리의 `migrations/0001_personal.sql`은 **개인화 전용 D1에만** 실행한다.
- 사용자 ID는 공통 계정 서비스가 검증한 UID만 허용한다. 브라우저가 전송한 user_id는 절대 신뢰하지 않는다.
- 개인화 API는 인증 서버의 세션 검증 방식을 확인한 뒤 별도 Worker로 구성한다. CORS만으로 인증을 대신하지 않는다.
- 저장 대상: 즐겨찾기 지역, 기본 지역, 활동/알림/화면 설정.
- 저장 제외: 현재 GPS 원시 위치, 예보 응답, 날씨 캐시, 로그인 비밀값.
- 첫 동기화에서 기존 로컬 데이터는 사용자 확인 후 병합하고, 서버 데이터 덮어쓰기 전에 백업한다.
- 로그아웃 시 개인화 로컬 캐시를 제거하거나 계정별로 격리한다.

## 운영 반영 전 체크리스트
1. Cloudflare에서 개인화 D1 생성 및 UUID 확인
2. 공통 계정 세션 검증 계약 확인
3. 전용 Worker D1 바인딩 및 API 구현
4. 로컬/서버 데이터 병합 및 웹/Android 동기화 테스트
5. 배포 및 운영 검증

**주의:** 이 커밋은 스키마와 분리 원칙을 추가하는 단계이며 D1 생성이나 운영 동기화가 완료되었다는 의미가 아니다.
