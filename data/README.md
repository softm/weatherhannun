## 공식 기상·대기질 배포 스냅샷

- `official/latest.json`은 브라우저에 비밀키를 배포하지 않기 위한 정규화 자료 계약입니다.
- GitHub Pages 배포 작업은 `KMA_API_HUB_KEY`, `DATA_GO_KR_SERVICE_KEY` Secrets가 모두 있을 때만 기상청 지상관측(현재/전일 같은 시각), 현재 특보, HSR 레이더 관측 이미지와 에어코리아 측정값을 갱신합니다. 공공데이터포털 키는 URL 인코딩 전의 일반 인증키를 등록합니다.
- 키가 없거나 실제 응답 검증이 실패하면 기존 파일을 공식 실측으로 가장하지 않고 `status: unconfigured` 또는 배포 실패 상태를 유지합니다.
- 공개 JSON에는 원천 인증키가 포함되지 않으며 공급자, 원문·약관 URL, 승인 상태와 관측/측정시각을 함께 기록합니다.
- WH-H02는 동일 기상청 관측소의 24시간 간격 자료가 모두 있을 때만 계산합니다. 자료가 없으면 큰 오류 카드 대신 `관측 자료 대기` 상태를 표시하고 모델 예보로 차이를 대신 만들지 않습니다.
- 공식 특보는 최신 스냅샷의 지역명과 현재 선택 지역을 대조해 지역 적용 건을 우선 표시합니다. 스냅샷이 오래됐거나 미연동이면 `특보 없음`으로 단정하지 않고 기상청 원문 확인 상태를 유지합니다.
