PRIVACY POLICY

개인정보처리방침

시행일: 2026년 10월 26일

날씨한눈 운영자(이하 “운영자”)는 날씨한눈 웹 서비스와 Android 앱 이용자의 개인정보를 중요하게 생각합니다. 본 방침은 서비스가 어떤 정보를 이용하고 어떻게 보호하는지 설명합니다.

1. 처리하는 정보와 이용 목적

위치정보이용자가 위치 기능을 선택·허용하면 브라우저 Geolocation API에서 현재 위치 좌표를 받습니다. 앱은 날씨 조회용으로 소수점 3자리(약 100m 단위)로 줄여 사용·기기 로컬 저장하며, 좌표는 날씨 API 제공 사업자에게 조회 요청 시 전달됩니다. 운영자 계정 서버에 별도로 보관하지 않습니다.
선택 지역·설정최근 선택한 지역(위치명과 좌표), 최대 10개 관심 지역 및 사용자가 수정한 이름, 위치 사용 안내 확인 상태, 알림 조건 등을 기기 또는 WebView의 로컬 저장소에 저장합니다. 위치 권한을 허용한 경우 마지막 선택 방식이 GPS일 때만 재진입 시 자동 위치 조회를 시도합니다.
기술 정보서비스 제공 과정에서 호스팅·네트워크 사업자가 일반적인 접속 로그, IP 주소, 기기·브라우저 정보를 처리할 수 있습니다.

2. 제3자 서비스

날씨·대기질 및 지도 표시를 위해 다음 외부 서비스를 사용합니다. 날씨 조회 시 선택 지역 또는 위치 좌표가 해당 서비스로 전송될 수 있으며, 각 사업자의 방침이 적용됩니다.

  • Open-Meteo: 날씨·대기질·지역 검색 데이터
  • OpenStreetMap: 지도 타일 및 지도 데이터
  • GitHub Pages: 웹 서비스 호스팅

3. 광고 및 식별자

현재 공개 릴리스에서는 광고 요청을 비활성화합니다. Android 앱에는 향후 광고 운영을 위한 Google Mobile Ads 및 Kakao AdFit 구성 요소가 포함될 수 있으나, 날씨 데이터의 상업 이용 권한과 앱 전용 광고 설정을 확인하기 전에는 운영 광고를 요청하지 않습니다. 광고를 활성화할 경우 관련 수집 항목, 동의 절차와 제3자 제공 내용을 이 방침에 반영합니다.

4. 보유 기간과 삭제

운영자는 위치정보와 선택 지역 정보를 별도 회원 계정 서버에 보관하지 않습니다. 저장 지역은 날씨한눈의 '지역관리'에서 개별 삭제할 수 있고, 선택 중인 지역은 다른 지역으로 전환됩니다. 모든 로컬 설정은 앱 데이터 삭제, 앱 제거 또는 브라우저 사이트 데이터 삭제로 지울 수 있습니다. 외부 서비스의 접속 기록 보유 기간은 각 사업자의 정책을 따릅니다.

5. 권한

위치 권한은 선택 사항입니다. 첫 방문에 현재 위치 사용·직접 지역 선택·나중에 설정 중 선택할 수 있습니다. 거부해도 지역 검색으로 이용 가능하며 반복적인 권한 팝업을 띄우지 않습니다. 브라우저 사이트 설정 또는 Android 앱 권한 설정에서 언제든 변경할 수 있습니다.

6. 아동의 개인정보

서비스는 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 별도 회원가입이나 이용자 프로필 기능을 제공하지 않습니다.

7. 방침 변경

서비스 기능이나 관련 법령이 변경되면 본 방침을 수정하고 시행일을 이 페이지에 표시합니다.
