개인정보처리방침

시행일: 2026년 10월 27일

날씨한눈 운영자(이하 “운영자”)는 날씨한눈 웹 서비스와 Android 앱 이용자의 개인정보를 중요하게 생각합니다. 본 방침은 서비스가 어떤 정보를 이용하고 어떻게 보호하는지 설명합니다.

1. 처리하는 정보와 이용 목적

위치정보이용자가 위치 기능을 선택·허용하면 브라우저 Geolocation API에서 현재 위치 좌표를 받습니다. 앱은 날씨 조회용으로 소수점 3자리(약 100m 단위)로 줄여 사용·기기 로컬 저장하며, 좌표는 날씨 API 제공 사업자에게 조회 요청 시 전달됩니다. 운영자 계정 서버에 별도로 보관하지 않습니다.
선택 지역·설정최근 선택한 지역(위치명·약 100m로 반올림한 좌표·주변 추정주소), 최대 10개 관심 지역 및 사용자가 수정한 이름, 위치 사용 안내 확인 상태, 역지오코딩 주소 캐시(최대 30일), 알림 조건, 향후 권한이 활성화될 Plus 활동 우선순위·프리셋과 Android 위젯 테마 등을 기기 또는 WebView의 로컬 저장소에 저장합니다. 위치 권한을 허용한 경우 마지막 선택 방식이 GPS일 때만 재진입 시 자동 위치 조회를 시도합니다.
농업 계획·리포트농업 Premium 계획은 사용자가 선택한 현재·저장 지역의 좌표로 시간별 예보를 조회하여 브라우저 메모리에서 계산합니다. 작물·생육단계와 생성 리포트를 운영자 서버에 저장하지 않습니다. 사용자가 ‘근거 리포트 저장’을 누른 경우에만 텍스트 파일을 기기에 내려받습니다. 현재 판매·실행 게이트는 비활성입니다.
Android 날씨 알림이용자가 알림 조건을 직접 저장하고 알림 권한을 허용하면 Android 앱은 저장한 지역의 좌표와 알림 기준을 기기에 보관하고, 앱이 닫혀 있어도 약 15분 주기의 시스템 작업에서 Open-Meteo에 예보를 요청할 수 있습니다. 알림 조건을 모두 끄면 해당 백그라운드 작업을 취소합니다.
Google Play 구매현재 유료 상품 판매는 비활성입니다. 향후 Plus 또는 농업 Premium 판매가 승인되면 Google Play가 결제와 구독 상태를 처리하며, 앱은 권한 확인을 위해 패키지명·상품 ID·구매 토큰·구매 시각을 운영자의 HTTPS 검증 서버에 전송할 수 있습니다. 구매 토큰은 WebView, JavaScript, 분석 이벤트에 제공하지 않으며 정확한 위치나 농작업 계획을 구매 검증 요청에 포함하지 않습니다.
선택형 품질 측정기본 OFF입니다. 이용자가 설정에서 직접 동의한 경우에만 화면 열기·예보 성공/실패·기능 버튼 사용 횟수를 날짜별 합계로 최대 35일 동안 이 기기의 로컬 저장소에 보관합니다. 사용자 ID, IP 주소, 좌표, 주소, 지역명, 검색어와 자유 입력값은 기록하지 않으며 현재 버전은 해당 합계를 운영자 서버나 제3자 분석 서비스로 전송하지 않습니다. 동의를 끄거나 기록 삭제 버튼을 누르면 로컬 합계를 삭제합니다.
기술 정보서비스 제공 과정에서 호스팅·네트워크 사업자가 일반적인 접속 로그, IP 주소, 기기·브라우저 정보를 처리할 수 있습니다.

2. 제3자 서비스

날씨·대기질 및 지도 표시를 위해 다음 외부 서비스를 사용합니다. 날씨 조회 시 선택 지역 또는 위치 좌표가 해당 서비스로 전송될 수 있으며, 각 사업자의 방침이 적용됩니다.

  • Open-Meteo: 날씨·대기질 모델 데이터
  • 국내 법정동·읍면리 정적 검색 자료: 2026년 2월 기준. 지역명 검색은 브라우저에서 처리하며 입력한 검색어를 외부 주소 API로 전송하지 않습니다.
  • OpenStreetMap: 지도 타일 및 지도 데이터. GPS 주소 표시에 필요한 주변 시·군·구·동과 도로명을 조회하기 위해 좌표 소수점 3자리(약 100m 수준)를 Nominatim 역지오코딩에 전송할 수 있습니다. 반환된 추정 주소를 기기 내에 저장·재사용합니다.
  • GitHub Pages: 웹 서비스 호스팅
  • Google Play: 유료 상품 판매가 승인된 Android 빌드에서 결제·구독 상태 처리. 현재 판매 기능은 비활성입니다.

3. 광고 및 식별자

현재 공개 릴리스에서는 광고 요청을 비활성화합니다. Android 앱에는 향후 광고 운영을 위한 Google Mobile Ads 및 Kakao AdFit 구성 요소가 포함될 수 있으나, 날씨 데이터의 상업 이용 권한과 앱 전용 광고 설정을 확인하기 전에는 운영 광고를 요청하지 않습니다. 광고를 활성화할 경우 관련 수집 항목, 동의 절차와 제3자 제공 내용을 이 방침에 반영합니다.

4. 보유 기간과 삭제

운영자는 위치정보와 선택 지역 정보를 별도 회원 계정 서버에 보관하지 않습니다. 저장 지역은 날씨한눈의 '지역관리'에서 개별 삭제할 수 있고, 선택 중인 지역은 다른 지역으로 전환됩니다. 선택형 기기 내 품질 합계는 최대 35일 보관하며 설정에서 즉시 삭제할 수 있습니다. 모든 로컬 설정은 앱 데이터 삭제, 앱 제거 또는 브라우저 사이트 데이터 삭제로도 지울 수 있습니다. 외부 서비스의 접속 기록 보유 기간은 각 사업자의 정책을 따릅니다.

5. 권한

위치 권한과 알림 권한은 선택 사항입니다. 첫 방문에 현재 위치 사용·직접 지역 선택·나중에 설정 중 선택할 수 있습니다. 위치 권한을 거부해도 지역 검색으로 이용 가능하며 반복적인 권한 팝업을 띄우지 않습니다. 알림 권한을 거부해도 앱 안의 날씨와 설정된 조건은 확인할 수 있습니다. 브라우저 사이트 설정 또는 Android 앱 권한 설정에서 언제든 변경할 수 있습니다.
