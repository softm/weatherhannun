# 날씨한눈 · Weather Hannun

예보를 읽는 것에서 끝나지 않고 **오늘 무엇을 할지** 판단하도록 돕는 반응형 날씨 웹앱입니다.

## 기능

- 실시간에 가까운 현재 날씨, 시간별 36시간 예보, 7일 예보, 기온·강수·풍속 정보
- 농작업(방제·수확), 산책, 세차, 빨래별 추천 시간대와 위험요인
- 미세먼지·초미세먼지 예측값(실측 아님)
- 국내 주요 도시 지도 비교, 모바일 지도 집중모드 및 메뉴 펼침
- 지역검색, 현재 위치 권한 요청, 마지막 선택 지역 저장 및 URL 공유
- 데이터 갱신 상태/원천 투명성(`data-status.html`)
- 모바일 우선 접근성, PWA 설치 지원 및 캐시

## 2차 개선 (2026-10-22)

- **48시간 / 3일 / 7일 / 날짜 범위**의 비 가능성 높은 구간, 맑은 낮 시간대 탐색
- 앞으로 48시간의 서리·저온·돌풍·관수 참고 가이드 (농약 살포 지시·현장 안전 판단 아님; 방제 점수는 미확인 현장조건을 반영하지 못해 85점이 상한)
- 브라우저 안에 저장하는 강수·저온·돌풍 알림 조건과 **앱이 열려 있는 동안에만** 브라우저 알림 표시. 서버 웹푸시는 아직 구현하지 않음
- 기상청 공식 기상특보 페이지 링크 (앱 내 특보 실시간 API 연동 전)
- 날씨 데이터는 7일 시간별 모델 예보를 분석하고, 활동 추천 시간은 처음 48시간 이내로 제한

## 3차 개선 — 전문가 합동 기획 적용 (2026-10-25)

실제 외부 자문이 아닌 PM·기상 데이터 전문가·기상캐스터 3개 관점의 가상 기획 검토를 코드에 반영했습니다.

- **10초·30초 브리핑**: 실측인 것처럼 꾸미지 않는 기상 모델 수치 기반 해설. 서버에서 생성형 AI를 호출하지 않습니다.
- **예보 변화 카드**: 강수 가능성 증가(확률/시간당 강수량), 돌풍, 기온 변화, 저온/고온 조건. 기상특보와 별개입니다.
- **해설 근거 보기**: 현재 기온·12시간 강수확률 최대·24시간 돌풍 최대·예보 유효시각·PM2.5 예측값
- **관심 지역 최대 5곳**: 검색한 지역을 브라우저 저장소에 보관, 이동/삭제 가능.
- **관심 활동 저장**: 산책·외출을 일반 사용자 기본값으로 사용하고 선택한 관심 활동을 저장.
- **모델과 관측 구분**: 첫 화면에 '모델 예보 · 실제 관측 아님', API 재조회 시각과 저장된/오래된 캐시 표시.
- **모바일·PWA**: 캐시 업데이트 방식 보완, 기존 집중지도/활동/대기질/주간예보 유지.
- **핵심 검증**: `node --test tests/briefing-core.test.cjs`
- **프로덕트 명세**: `docs/EXPERT-PLAN.md`, `docs/FORECAST-CONTRACT.md`

## 실행

정적 웹앱입니다. 루트 `index.html`을 HTTP 정적 서버로 열거나 GitHub Pages로 배포하세요.

```bash
python3 -m http.server 8080
```

## 데이터 및 운영 유의사항

첫 버전은 [Open-Meteo](https://open-meteo.com/) Forecast API와 Air Quality API(예측 모델)를 클라이언트에서 직접 사용합니다. 데이터: Open-Meteo.com (CC BY 4.0), 원 데이터/모델은 각 출처 표기를 따릅니다. 무료 비상업 API는 **광고/유료 서비스에 사용하면 안 됩니다**. 광고를 도입하기 전에 기상청 공공데이터 API + 안전한 서버 측 키 관리 또는 Open-Meteo 상업용 라이선스로 전환하세요.

- 판단 점수는 공개 예보 변수를 바탕으로 한 안내용 휴리스틱이며, 기상특보·관측 실측·전문 농업 자문을 대체하지 않습니다.
- 농약 방제 여부는 등록 농약의 사용기준, 농약안전정보시스템, 현장 풍향/풍속과 강수 및 주변 환경을 우선하세요.
- Open-Meteo 대기질은 관측소 실측과 다를 수 있습니다.
- 위치는 이용자가 허용할 때만 웹 브라우저에서 사용합니다.
