# 날씨한눈 · Weather Hannun

예보를 읽는 것에서 끝나지 않고 **오늘 무엇을 할지** 판단하도록 돕는 반응형 날씨 웹앱입니다.

## 기능

- 실시간에 가까운 현재 날씨, 시간별 36시간 예보, 7일 예보, 기온·강수·풍속 정보
- 농작업(방제·수확), 산책, 세차, 빨래별 추천 시간대와 위험요인
- 미세먼지·초미세먼지 예측값(실측 아님)
- 국내 주요 도시 지도 비교, 모바일 지도 집중모드 및 메뉴 펼침
- 지역검색, 현재 위치 권한 요청, 마지막 선택 지역 저장 및 URL 공유
- 데이터 갱신 상태/원천 투명성(`data-status.html`)
- 모바일 우선 접근성, PWA 설치 지원 및 캐시

## 2차 개선 (2026-10-22)

- **48시간 / 3일 / 7일 / 날짜 범위**의 비 가능성 높은 구간, 맑은 낮 시간대 탐색
- 앞으로 48시간의 서리·저온·돌풍·관수 참고 가이드 (농약 살포 지시·현장 안전 판단 아님; 방제 점수는 미확인 현장조건을 반영하지 못해 85점이 상한)
- 브라우저 안에 저장하는 강수·저온·돌풍 알림 조건과 **앱이 열려 있는 동안에만** 브라우저 알림 표시. 서버 웹푸시는 아직 구현하지 않음
- 기상청 공식 기상특보 페이지 링크 (앱 내 특보 실시간 API 연동 전)
- 날씨 데이터는 7일 시간별 모델 예보를 분석하고, 활동 추천 시간은 처음 48시간 이내로 제한

## 3차 개선 — 전문가 합동 기획 적용 (2026-10-25)

실제 외부 자문이 아닌 PM·기상 데이터 전문가·기상캐스터 3개 관점의 가상 기획 검토를 코드에 반영했습니다.

- **10초·30초 브리핑**: 실측인 것처럼 꾸미지 않는 기상 모델 수치 기반 해설. 서버에서 생성형 AI를 호출하지 않습니다.
- **예보 변화 카드**: 강수 가능성 증가(확률/시간당 강수량), 돌풍, 기온 변화, 저온/고온 조건. 기상특보와 별개입니다.
- **해설 근거 보기**: 현재 기온·12시간 강수확률 최대·24시간 돌풍 최대·예보 유효시각·PM2.5 예측값
- **관심 지역**: 기존 즐겨찾기를 4차 위치관리로 마이그레이션. 이름 변경 및 삭제, 최대 10곳 지원.
- **관심 활동 저장**: 산책·외출을 일반 사용자 기본값으로 사용하고 선택한 관심 활동을 저장.
- **모델과 관측 구분**: 첫 화면에 '모델 예보 · 실제 관측 아님', API 재조회 시각과 저장된/오래된 캐시 표시.
- **모바일·PWA**: 캐시 업데이트 방식 보완, 기존 집중지도/활동/대기질/주간예보 유지.
- **핵심 검증**: `node --test tests/briefing-core.test.cjs`
- **프로덕트 명세**: `docs/EXPERT-PLAN.md`, `docs/FORECAST-CONTRACT.md`

## 4차 개선 — 첫 진입 GPS 권한 및 지역 관리 (2026-10-26)

- **첫 방문 위치 온보딩**: 브라우저가 사용자 동작 없이 권한 팝업을 제한할 수 있으므로, 첫 방문에 보안 HTTPS 기반 '현재 위치 사용' 버튼을 표시합니다. 버튼을 누르면 `navigator.geolocation.getCurrentPosition`으로 권한 요청 및 위치 획득.
- **다음 방문 자동 조회**: 이전에 현재 위치 사용을 선택하고 브라우저 권한이 이미 허용된 경우에만 GPS 재조회. 직접 선택한 지역은 자동으로 덮어쓰지 않음.
- **현재 위치 기억**: 위도·경도를 소수점 3자리(약 100m 단위)로 줄여 브라우저 `localStorage`에 저장. 날씨 API 호출에는 선택 좌표가 전달되며 별도 회원 계정 서버에 보관하지 않습니다.
- **빠른 지역 전환**: 상단 현위치/저장 지역 칩, 위치 검색과 빠른 선택, '+'로 지역 관리.
- **여러 지역 저장·수정·삭제**: 최대 10개, 사용자 지정 이름, 삭제 실행 취소. 선택 중인 지역 삭제 시 다른 저장 지역(없으면 기본 지역)으로 이동.
- **기존 설정 자동 이관**: `weatherhannun_favorite_locations_v1` → `weatherhannun_places_v2`.
- **권한 거부 안전 경로**: 권한 거절 시 재요청 반복하지 않고 지역 검색 안내, 언제든 수동 재시도 가능.
- **위치 공유 보호**: GPS·수동·저장 지역 선택 시 좌표를 주소창에 자동으로 넣지 않음. 사용자가 '공유'를 누르면 공유 링크 좌표 포함.
- **자동검증**: `node --test tests/*.test.cjs`
- **운영가이드**: `docs/LOCATION-UX.md`

## 5차 개선 — GPS 위치의 실제 행정주소 표시

- GPS 좌표를 **시·군·구·동과 주변 도로명**으로 변환해 상단 현재 위치, 빠른 지역 선택, 저장 지역에 표시합니다.
- 예: `부천시 소사구 옥길동` / `경기도 부천시 소사구 옥길동 · 옥길로 인근 (GPS 기준 추정주소)`
- 위·경도는 소수점 3자리(약 100m 수준)로 줄여 <https://nominatim.openstreetmap.org/> 역지오코딩에 요청합니다. 주소 응답은 브라우저에 최대 30일 캐시합니다.
- Nominatim 공개 서비스는 **1회/초 상한, 식별 가능 Referer, 출처 표기** 조건이 있습니다. 이용자가 늘면 상용/자체 역지오코딩으로 교체해야 합니다.
- 건물번호를 보장할 수 없으므로 정확한 도로명주소가 아닌 **주변 추정주소**임을 표시합니다. 조회 실패 시 좌표 안내를 사용하며 날씨는 계속 조회합니다.
- `node --test tests/*.test.cjs`로 한국 주소 포맷, 캐시, GPS 재진입, 다른 위치로 전환 시 비동기 경합을 테스트합니다.

## 6차 개선 — 토지이용한눈 방식의 전국 주소 검색 (2026-10-26)

- 기존 Open-Meteo 도시명 검색을 **국내 법정 행정구역 검색**으로 교체했습니다. 토지이용한눈의 주소·장소별 결과 구분 UX를 참고하되, 기존 VWorld 도메인 전용 API 키를 재사용하지 않습니다.
- 전국 시·도/시·군·구/읍·면·동/리 약 19,574개를 포함한 2026년 2월 기준 법정동 데이터를 `data/korea-regions-202602.json`으로 GHP에 배포합니다.
- 입력 중 후보 즉시 검색: `옥길동`은 부천/광명을 구분하고, `부천 소사구 옥길동`은 해당 법정동, `서산 화곡리`는 충청남도 서산시 대산읍 화곡리를 표시합니다.
- 각 후보에 시·군·구를 포함한 **전체주소**와 법정동/읍/면/리 유형을 표시합니다. 선택하면 그 지역의 **대표 좌표**로 날씨가 즉시 변경됩니다.
- 선택한 지역의 전체주소를 저장하고 기존 관심 지역 저장·이름 변경·삭제와 연동합니다. 위치는 건물/필지의 정확한 주소가 아닌 행정구역의 중심점입니다.
- 번지 숫자가 포함된 `옥길동 123-4`는 동 단위로만 조회하며 숫자가 무시됐다는 안내가 표시됩니다. `세종대로 110` 같은 도로명·건물번호 단독 검색은 아직 지원하지 않습니다.
- 검색어는 외부 주소 API로 보내지 않고 브라우저에서 정적 인덱스를 검색합니다. 지역 데이터의 2026년 2월 이후 개편은 반영되지 않을 수 있습니다.
- 데이터 출처 및 이용 안내: [data/README.md](data/README.md). 테스트: `node --test tests/*.test.cjs`.

## 7차 개선 — Stitch 전 화면 디자인·기능 적용 (2026-10-26)

- Google Stitch 프로젝트 `10523118221126758140`의 화면 구성과 디자인 토큰을 `DESIGN.md`에 정리하고 실제 UI에 적용했습니다.

- 시간별 기간 필터, 주간 날짜 상세 펼침, 활동 카테고리 필터와 활동 카드→상세 연결, 대기질·알림 바로가기를 실제 예보 데이터 및 기존 기능과 연결했습니다.
- Android 앱은 이 웹앱을 WebView로 표시하므로 운영 URL이 갱신되면 동일한 화면과 기능을 사용합니다.

## 데이터 및 운영 유의사항

첫 버전은 [Open-Meteo](https://open-meteo.com/) Forecast API와 Air Quality API(예측 모델)를 클라이언트에서 직접 사용합니다. 데이터: Open-Meteo.com (CC BY 4.0), 원 데이터/모델은 각 출처 표기를 따릅니다. 무료 비상업 API는 **광고/유료 서비스에 사용하면 안 됩니다**. 광고를 도입하기 전에 기상청 공공데이터 API + 안전한 서버 측 키 관리 또는 Open-Meteo 상업용 라이선스로 전환하세요.

- 판단 점수는 공개 예보 변수를 바탕으로 한 안내용 휴리스틱이며, 기상특보·관측 실측·전문 농업 자문을 대체하지 않습니다.
- 농약 방제 여부는 등록 농약의 사용기준, 농약안전정보시스템, 현장 풍향/풍속과 강수 및 주변 환경을 우선하세요.
- Open-Meteo 대기질은 관측소 실측과 다를 수 있습니다.
- 위치는 이용자가 허용할 때만 웹 브라우저에서 사용합니다.
