## 구현 원칙

1. 기존 app.js·forecast-insights.js·briefing-core.js의 데이터 처리와 ID 바인딩을 유지합니다.
2. stitch-layout.js는 app.js보다 먼저 로드해 기존 data-view 클릭 이벤트가 새 탭에도 연결되도록 합니다.
3. 신규 시간별 탭은 기존 DOM 위젯을 재배치하므로 중복 예보 요청이 없습니다.
4. 모바일 하단 5탭(오늘/시간별/주간/활동추천/전국지도)을 유지하고, 설정은 모바일·데스크톱 공통 상단 톱니바퀴 아이콘으로 접근합니다. 대기질은 오늘 화면 빠른 링크 및 데스크톱 메뉴로 접근합니다.
5. 라이트·다크 테마는 설정 화면에서 고르며 localStorage에 저장합니다. 저장값이 없으면 라이트 모드로 시작합니다.
6. Open-Meteo 데이터의 상업 이용 조건, 공식 특보 표시 제한, 개인정보 및 광고 운영 조건은 별개로 준수해야 합니다.
7. AdMob/AdFit은 Android 네이티브 광고 시스템이며, 본 웹 디자인에서는 광고를 콘텐츠로 위장하지 않습니다.

## 2026-11-02 모바일 정보 구조 개편

- 기존 Stitch 색상·카드·아이콘을 유지하고 `mobile-experience.css`에서 모바일 읽기 크기, 10px 간격, 44px 이상 주요 터치 영역, 선택 상태와 다크모드 대비를 보완한다.
- 오늘: 현재 날씨와 12시간 강수 판단 → 다음/준비·하루 변화·아나운서/10초·30초 브리핑 → 시간별 미리보기 → 활동/옷차림 → 대기질 → 3일 주간 미리보기. 보조 지표와 출처는 펼침 및 데이터 상세로 이동한다. 지역에 적용되는 공식 특보는 접힌 영역 밖에 우선 노출한다.
- 시간별: `hourly-explorer-core.js`가 실제 제공 구간과 결측을 보존하고, `hourly-explorer.js`가 24/48시간·7일·날짜 범위, 가로 차트/타임라인 선택, 키보드 이동, 한 시점 상세, 선택 기간 전체 표를 담당한다. 홈 시간/주간 미리보기는 선택한 시각/날짜의 상세로 연결한다.
- 데이터 공급자, GPS/저장 지역, 전국 지도 임시 조회, API 전환, 로그인·알림·광고/구독 안전 게이트는 기존 계약을 사용한다. Android는 동일 GitHub Pages를 로드하며 별도 웹 자산 복사본이 없다. 네이티브 상단 인셋 중복 방지와 시작 시 1회 캐시 재검증 정책을 유지한다.

검증:
- `node --test tests/*.test.cjs`: 239개 단위/계약 테스트.
- `npx playwright test tests/e2e/mobile-experience.spec.mjs`: 7개 폭(320/360/375/390/430/768/1280)에서 주요 5개 화면, 다크모드, 타임라인/차트/키보드/펼침/주간, 주소 검색/GPS/저장 지역/임시 지도, 새로고침, 브리핑, 특보, 명암/터치/하단 메뉴 가림을 검증한다. Verify web app CI에 추가했다.
- 동일한 실제 예보 응답 고정 비교에서 390px 오늘 콘텐츠 약 2,666px → 2,235px(약 16% 감소), 시간별 4,067px → 1,291px(약 68% 감소). 전체 문서/브라우저 크롬을 제외한 활성 화면 높이다. 공급자 응답과 사용자 선택에 따라 길이는 달라진다.
- 테스트의 통합 API 503·대기질 503은 실패 처리 검증을 위한 라우팅이며, `tests/fixtures/mobile-weather.json`은 실제 조회한 서울 모델 예보다. 운영 API 가용성은 이 테스트 결과로 보증하지 않는다. 실제 공급자 연결 상태는 운영 데이터 안내에서 별도로 확인한다.
- 실행별 스크린샷·실패 추적은 `test-results/` 및 GitHub Actions `mobile-ui-results` 아티팩트로 남기며 소스 저장소에 대용량 이미지를 넣지 않는다.

시간별 첫 시점은 관측 응답의 과거 시각이 아니라 실제 KST 현재 시간으로 정한다. UI 회귀 테스트는 기록 응답의 시각으로 브라우저 시계를 고정한다.
