- Stitch 확인일: 2026-10-25
- 확인 결과: 페이지 8개(오늘/시간별/주간/활동 각각 라이트·다크) + SVG 아이콘 10개
- HTML 원본은 디자인 참조용이며, **Stitch 화면에 포함된 고정 날씨 수치·추천 문구를 서비스 데이터로 치환하지 않습니다.**

## 구현 원칙

1. 기존 app.js·forecast-insights.js·briefing-core.js의 데이터 처리와 ID 바인딩을 유지합니다.
2. stitch-layout.js는 app.js보다 먼저 로드해 기존 data-view 클릭 이벤트가 새 탭에도 연결되도록 합니다.
3. 신규 시간별 탭은 기존 DOM 위젯을 재배치하므로 중복 예보 요청이 없습니다.
4. 모바일 하단 5탭(오늘/시간별/주간/활동추천/전국지도)을 적용합니다. 대기질은 오늘 화면 빠른 링크 및 데스크톱 메뉴로 접근합니다.
5. 테마 설정은 localStorage에 저장합니다. 최초 로드는 운영체제 선호 모드를 따릅니다.
6. Open-Meteo 데이터의 상업 이용 조건, 공식 특보 표시 제한, 개인정보 및 광고 운영 조건은 별개로 준수해야 합니다.
7. AdMob/AdFit은 Android 네이티브 광고 시스템이며, 본 웹 디자인에서는 광고를 콘텐츠로 위장하지 않습니다.

- 브라우저 뷰포트 360px/390px/768px/PC, 라이트/다크

- 네트워크 오류/오프라인 및 새로고침 후 서비스워커 캐시
