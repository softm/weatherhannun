| 알림·기상·지도 | 기존 기능 유지 | 관련 지역의 날씨 표시 |

## 프런트엔드 구성

- \`location-core.js\`: 유효 좌표, 동일 지역 판정, 목록 중복 제거, 최대 10곳, 저장·이름 변경·삭제, 활성 지역 삭제 후 대체 선택.
- \`location-manager.js\`: 브라우저 Geolocation/Permissions API, 온보딩, 칩/관리 패널, 저장소 V1→V2 이관, 삭제 실행 취소.
- \`location-manager.css\`: 모바일 우선, Stitch 라이트/다크 토큰 재사용, 스크린리더·키보드 조작에 맞춘 기본 구조.
- \`app.js\`: 선택 지역 적용, 마지막 위치 유지, GPS 선택 시 URL에 좌표 자동 삽입 방지, 기존 날씨/지도 기능과 결합.
- \`briefing-ui.js\`: 기존 관심지역 구현 제거, 날씨 브리핑만 책임(중복 이벤트 방지).

### 브라우저 저장 키

## 개인정보·정밀도

- 기기 위치는 \`navigator.geolocation\`으로 이용자가 명시적으로 허용할 때 읽는다.
- Geolocation API 자체의 위치 조회는 장치 권한/플랫폼 정책에 따른다.
- 받은 좌표는 소수점 3자리(약 100m 수준)로 낮춘 뒤 날씨 조회·로컬 저장에 사용한다.
- 이용자가 링크 공유를 요청하기 전에는 GPS 및 수동 선택 지역 좌표가 브라우저 주소창에 자동 삽입되지 않는다.
- 직접 지역 검색은 배포된 2026.02 법정 행정구역 정적 인덱스를 브라우저에서 조회하며, 검색어를 제3자 주소 API로 전송하지 않는다.
- 현재위치 역지오코딩(정확한 도로명/동 표시)은 별도 인증 및 개인정보/쿼터 검토 전 구현하지 않는다. GPS 이름은 '내 현재 위치'로 표시하고 원하는 별명으로 저장할 수 있다.
- 사이트 접속 시 IP/기술정보, API 날씨 요청의 선택 좌표는 외부 서비스 제공자에게 전달될 수 있다.
- 권한 부여 자체는 브라우저/운영체제가 관리하며 사이트에서는 강제 변경/해제할 수 없다.

## 운영 전 브라우저 회귀 점검

1. 새 시크릿 창/새 사이트 데이터: 온보딩 표시 → 현위치 버튼 누름 → 브라우저 권한창 → 허용 → 현재 위치 날씨.
2. 새 시크릿 창: 위치 거부 → 지역검색/지역 선택 계속 가능, 재진입 시 팝업 반복 없음.
3. 수동 지역 선택 후 새로고침: 선택 지역 보존, GPS로 자동 덮어쓰지 않음.
4. 현위치 선택 후 새로고침: 위치권한이 이미 허용되었다면 GPS 재조회.
5. 저장한 지역 2곳 이상 클릭하여 예보 변경, 각 지역 이름 수정/삭제 실행 취소.
6. 현재 선택 중인 지역 삭제: 다른 저장 지역 우선, 없으면 기본 지역. 목록 관리창 유지.
7. 기존 \`weatherhannun_favorite_locations_v1\` 값이 있는 브라우저에 배포: v2로 이관.
8. 데스크톱과 Android Chrome/WebView로 테스트; WebView는 네이티브 위치권한 승인 처리가 필요할 수 있음.
9. HTTPS/위치 권한 미지원 환경: 검색 경로가 항상 남아 있음.
10. PWA 서비스워커 업데이트 후 구버전 JS가 섞이지 않도록 최신 로딩 확인.

기상 특보, 공식 관측 API, 앱 종료 후 푸시 기능과는 독립적인 작업이며 이번 위치관리 변경으로 해당 기능을 완료했다고 표시하지 않는다.

## 5차: GPS 추정주소 표시 (2026-10-26)

- `reverse-geocode.js`: OpenStreetMap Nominatim `/reverse` API, `format=jsonv2`, `zoom=17`, `layer=address`, `accept-language=ko`.
- 좌표는 소수점 3자리로 줄여 요청하며 건물/번지 번호는 의도적으로 표시하지 않습니다.
- 시·도/시·군·구/동, 가능한 경우 도로명 **인근** 표시. 정확한 집 주소가 아니라 *GPS 기준 추정주소*입니다.
- 상단 위치명과 주소 부제, 저장 지역 목록의 추정주소, 지역 버튼 툴팁으로 표시합니다.
- 결과는 로컬스토리지에 30일 캐시, 메모리 중복 요청 통합 및 1초 이상 간격의 순차 요청.
- 공용 Nominatim의 전체 요청 제한은 사용자 브라우저 간 보장할 수 없으므로 트래픽 증가 시 유료 지오코더 또는 직접 호스팅 전환이 필요합니다.
- 통신 장애·주소 미수집 시 GPS 좌표와 기존 날씨 조회 유지. 지역 전환 중 오래된 주소 응답 무시.
- 주소 데이터 및 출처 © OpenStreetMap contributors, ODbL. 제3자 위치 좌표 전송은 `privacy.html`에 안내.
- `tests/reverse-geocode.test.cjs`, `tests/location-flow.test.cjs`에서 검증.

## 6차: 토지이용한눈 방식 읍·면·동·리 검색 (2026-10-26)

- `data/korea-regions-202602.json`: 행정안전부 2026.02 법정동 코드 및 브이월드 경계 중심점에서 파생된 전국 19,574개 시도/시군구/읍면동/리 정적 데이터.
- `region-search-core.js`: 계층 주소 구성, 중복 행정동명 구분, 한국어 시도 약칭과 부분검색 및 적합도 정렬.
- `region-search-ui.js`: 입력 즉시 로컬 검색, 상위 행정구역과 결과 유형 표시, 결과 선택 시 기존 날씨앱 지역 변경 이벤트 발생.
- `region-search.css`: 검색창 바로 아래에서 열리는 모바일 우선 결과 카드, 전체주소·유형 구분, 키보드/접근성 지원.
- 예: `옥길동`은 광명·부천 후보 구분, `부천 소사구 옥길동`은 부천 선택, `서산 화곡리`는 서산시 대산읍 화곡리 선택.
- 접미사를 생략한 시 이름은 동일한 이름의 동·리보다 시 단계를 먼저 확정합니다. 예: `광명` → `경기도 광명시`.
- 번지 및 건물의 정확한 지오코딩은 아님. 지역의 대표 좌표로 날씨를 조회하며, 정확한 필지·도로명 위치와 차이가 있을 수 있습니다.
- 저장한 지역은 `regionCenter` 플래그와 전체주소가 함께 보관되어 GPS 추정주소와 구분됩니다.
- 정적 2026.02 기준 이후 법정동 신설·개편 시 데이터 갱신이 필요합니다. 출처·이용 조건은 `data/README.md` 참조.
- `reverse-geocode.js`는 GPS 좌표→주변 주소 변환으로 별도이며, 사용자가 직접 동/리 검색할 때 제3자 주소 API로 검색어를 보내지 않습니다.
- 테스트: `tests/region-search.test.cjs`, `tests/region-ui.test.cjs`; 기존 위치관리/GPS 테스트와 함께 실행합니다.

## 현재 지역 요약과 변경 모드 (2026-11-01)

- 모든 화면 상단에 ‘현재 날씨 지역’, 선택 지역명, GPS 추정 위치/지역 대표 위치/수동 선택 기준과 ‘변경’ 버튼만 표시합니다. 긴 지역명은 줄바꿈하고 모바일에서도 숨기지 않습니다.
- 저장 지역 나열, 현재 지역 저장, GPS 재조회, 검색·이름 수정·삭제·정렬은 ‘변경’으로 여는 기존 지역 관리 대화상자 안에서 제공합니다. 지역 비교는 전체 메뉴와 설정에서 접근합니다.
- 선택 즉시 상단 지역명이 갱신되며, 기존 수동 선택 저장·GPS 권한 정책을 유지합니다.

## 앱 바 통합 (2026-11-01)

- 별도 현재 지역 카드를 제거하고 앱 바에 지역명 버튼을 표시합니다. 앱 이름 대신 선택 지역을 중심 정보로 둡니다.
- 긴 지역명은 마지막 두 주소 구성요소를 우선 표시하고 넘치면 말줄임합니다. 버튼의 접근성 이름과 변경창에서는 전체 지역명을 확인할 수 있습니다.
- GPS 선택은 위치 추적 아이콘으로 구분하며, 지역명을 누르면 모바일 하단 변경창(PC는 기존 대화상자)에서 검색·GPS·저장 지역을 관리합니다.

- 앱 바 지역명 옆 ☆ 버튼으로 현재 보고 있는 지역을 즉시 저장합니다. 이미 저장된 지역은 비활성 ★로 표시하며, 삭제·이름 수정은 변경창에서 수행합니다.

- 상단 지역명 옆에 현위치 찾기 → ☆ 저장 순서로 버튼을 제공합니다. 현위치 조회는 직접 누를 때 권한을 요청하며, 조회 중에는 찾기 버튼을 비활성화합니다. 자동 저장하지 않고 조회된 지역을 사용자가 별도로 저장합니다.


## 전국 날씨 임시 조회 (2026-11-01)
- 전국 일기도는 7일 날짜와 현재/오전 09시/오후 15시(KST)를 선택한다. 미래 날짜에서는 현재를 비활성화한다. 현재도 공식 실황이 아닌 Open-Meteo 모델값이며 결측은 `--`로 표시한다.
- 주요 도시를 누르면 오늘(현위치 상세) 화면에서 그 지역을 임시 조회한다. 선택 날짜는 전국 비교용이며 상세 화면은 선택 지역의 현재부터 예보를 보여준다.
- 임시 조회는 기본 위치, 즐겨찾기, 기본 위치 예보 캐시, Android 알림·위젯·화면날씨 스냅샷을 덮어쓰지 않는다. 직접 지역 저장을 누른 경우에만 즐겨찾기에 추가한다.
- ‘기존 위치로 돌아가기’ 또는 앱 새 시작 시 기존 저장 위치로 돌아간다. 임시 조회 중에도 명시적 GPS/지역 선택은 기존 저장 동작을 따른다.
- 전국 지도는 대표 위치를 보기 쉽게 배치한 개략도이며 오전/오후 값은 구간 평균이 아닌 대표시각 예보다.
