대상: [날씨한눈 웹](https://softm.github.io/weatherhannun/) · [Android](https://github.com/softm/weatherhannun.android)  
목적: 사용자 만족도와 **실제 순이익** 동시 극대화. 경쟁사의 추정 매출/내부 통계는 확인할 수 없으므로 공개 Play 정보와 명확히 구분한다.

## 1. 포지셔닝

**날씨 예보를 보는 앱 → 지금 무엇을 할지 결정하는 앱.**

## 3. 현재 우리 앱과 차별화 구현

**보유:** Stitch 대시보드, 현위치/행정주소/최대 10개 지역, 10초·30초 브리핑/근거, 시간별·주간, 비/맑음 시간 탐색, 농작업·산책·세차·빨래 추천, 관심 알림, 지도 집중모드, PWA, 캐시·예보 시각 표시. (README 참조)

**이번 구현:** 오늘 첫 화면의 **12시간 비·우산 판단 카드**. 기존 시간별 모델 데이터를 재사용하며, 강수확률 50% 이상 또는 시간당 강수량 0.3mm 이상인 첫 연속 시간 구간을 안내한다. 결측이면 '모름', 연결 실패/오래된 캐시는 새로고침 권고, 비가 적어도 돌발 강수 가능성 안내. 분 단위 정확 예측, 실제 비가 내린다는 단정, 공식 특보라고 주장하지 않는다. 상세 버튼은 기존 시간별 예보로 이동. Android는 동일한 GitHub Pages를 WebView로 로드하므로 웹 배포 후 화면 공통 반영.

**우선순위:** (1) 상업 데이터 사용권 확보 (2) Android 홈 위젯: 현재 날씨/12h 비/갱신 시각, 위치 변경·새로고침 (3) 체감온도·옷차림 추천 (4) 공식 위험기상+레이더를 출처에 맞게 표시 (5) 관측-모델 예보 오차 평가/Brier Score (6) 선택형 유료화 실험.

### 릴리스 광고 활성화 차단 조건

현재 웹 프런트엔드는 Open-Meteo **비상업용 무료 API**(예보/대기질)를 직접 요청한다. 광고를 켜면 상업적 이용이므로 **운영 광고 활성화를 금지**한다. [Open-Meteo 유료 API](https://open-meteo.com/en/pricing)를 계약하고 키를 안전하게 보호하거나, [기상청 단기예보](https://www.data.go.kr/data/15139470/openapi.do) 등 [기상청 API허브](https://apihub.kma.go.kr/apiInfo.do) 데이터의 공공누리 유형 및 개별 이용 조건을 검증해 정식 전환해야 한다. 클라이언트·GitHub Pages에 공급자 비밀키를 노출하면 안 된다. Android 현재 차단 상태는 [광고 규칙](https://github.com/softm/weatherhannun.android/blob/main/docs/ADS.md) 참조.

AdMob 정책: [앱 실행/종료 전면광고 금지 및 반복 노출 제한](https://support.google.com/admob/answer/6201362?hl=ko). 날씨 앱처럼 빈번히 열고 즉시 닫는 도구는 자연스럽지 않은 전면광고를 피한다. 사용자 동의·개인정보처리방침·Play Console 정보 검증 필수.

### 가설적 매출 계산 (실매출, 경쟁사 수익 통계 아님)

월 광고매출 = **DAU × 하루 세션 수 × 세션당 유효 광고 노출 × 30 × eCPM ÷ 1,000**.  
예시: DAU 5,000 × 2세션 × 유효 노출 1.2 × 30일 × eCPM 2,000원 ÷ 1,000 = **월 720,000원(가정)**. 실제 수익은 유효 노출률·국가·광고 주제·동의율·수요에 따라 변하고 데이터 사용료·서버비·유지보수비 등을 차감해 순이익을 따져야 한다.

## 5. 측정할 지표와 실행 합격선 (목표 가설, 실측 아님)

| KPI | 의미 | 목표 가설 |
| --- | --- | --- |
| 예보 데이터 정상 응답률 | 날씨 제공 핵심 품질 | 99% 이상 |
| D1 / D7 / D30 유지율 | 신규 이용자 첫날/7일/30일 재방문 | 35% / 15% / 8% |
| 위젯 활성화율 | 설치 → 홈 위젯 추가 | 15% 이상 |
| 행동 카드 활용률 | 한 세션에 카드/상세 활용 | 10% 이상 |
| 광고수익/DAU (ARPDAU) | 광고 수익 생산성 | 실데이터로 기준선 확립 |
| 순이익/DAU | 총 매출 - 상업 데이터·광고/운영비 | 전월 대비 개선 |
| 강수 Brier Score/MAE | 검증된 관측과 모델 예보 비교 | 관측 연계 뒤 측정 |
| 충돌 없는 세션 | 앱 안정성 | 99.5% 이상 |

소량의 익명·동의된 이벤트만 계측. 위치좌표/이동 경로/농작업 세부정보를 광고 타깃팅에 전달하지 않는다. A/B 실험에서는 ARPDAU뿐 아니라 유지율·반감 리뷰·광고 정책을 함께 비교한다.
