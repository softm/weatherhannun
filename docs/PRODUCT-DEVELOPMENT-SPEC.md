## 0. 제품 결정과 변경 불가 원칙

**미션:** "오늘 무엇을 언제 하면 좋은지 알려주는 날씨 의사결정 서비스."

**경험 순서:** 현재 상태 → 무엇이 언제 변하는가 → 사용자에게 미칠 영향 → 지금 할 행동 → 예보의 출처·불확실성. 일반 사용자에게는 우산·옷차림·산책·빨래, 농업인에게는 농작업 시간대·저온·돌풍·강수 위험을 제공한다.

**북극성:** 신뢰할 수 있는 날씨 판단을 제공하며 D7/D30 재방문 및 사용자당 순이익을 개선. 광고 노출 개수, 체류시간만의 극대화를 목표로 삼지 않는다.

**지켜야 할 원칙**
1. 웹 프런트엔드는 softm/weatherhannun → GitHub Pages 단일 배포. Vercel에 복제 배포하지 않는다.
2. Android 코드는 softm/weatherhannun.android에만 둔다. WebView는 공식 GitHub Pages를 로드하고, 위젯·알림·오버레이·광고·결제는 네이티브 책임으로 나눈다.
3. Stitch 라이트/다크, 색상 토큰, 하단 5탭(오늘·시간별·주간·활동추천·전국지도), 모바일 지도 집중모드(compact → expanded → full)를 유지한다.
4. 관측·예보·공식 특보·기계적 추천 점수를 서로 혼동하지 않는다. 존재하지 않는 실측·분 단위 비 시작·서리 확정·기상특보를 만들어내지 않는다.
5. 정상 예보와 공식 위험정보의 핵심은 무료. 오버레이·알림·위젯으로 사용자를 압박하거나 광고 클릭을 유도하지 않는다.
6. 상업 이용권, 광고 앱별 매체 ID, 동의/개인정보 검증 전에는 Android Release 실광고 차단 유지. 유료 구독을 붙여도 비상업 무료 API를 계속 사용해서는 안 된다.
7. 권한은 필요할 때 사용자 행동에 따라 요청. 위치는 현위치/GPS뿐 아니라 수동 동·리 검색으로 항상 대체 가능.

## 4. 정보 구조와 상세 화면 스펙

### 4.1 오늘 (첫 화면, 기존 Stitch 유지)

표시 순서:
1. 현재 지역명(가장 구체적인 동/리, GPS 추정주소/행정구역 대표좌표 표기)·지역 빠른 전환·현위치·관리 버튼.
2. 주 날씨: 기온·아이콘·체감온도·최고/최저·현재 자료 유형(관측/모델)·유효/관측시각.
3. **기존 12시간 비·우산 판단 카드**: 비 가능성의 첫 시간대·연속 시간·최대 확률/예상량·불확실성. 자세히 → 시간별 탭.
4. 신규 **어제 같은 시각 비교**: 관측-관측이 확보됐을 때 온도차·강수차, 없으면 사유 설명. 다른 종류의 수치를 조용히 섞지 않는다.
5. 신규 **오늘 옷차림·우산 추천**: 체감온도/강수/바람 근거와 간결한 문장. 개인차 안내.
6. **기상 브리핑 10초/30초**, 안전한 색상 하이라이트·근거 펼침.
7. 사용자 관심 **활동 추천 TOP 3** (산책·빨래·농작업 등)와 상세 이동.
8. 오늘 시간별 미리보기, 대기질, 일몰 등 부가지표는 간결하게 접기/확장.
9. 기존 네이티브 하단 광고 슬롯과 웹 콘텐츠/하단 탭 사이에는 조작 혼동이 없는 별도 공간.

화면 기준: 최소 320px 대응, Stitch 주요 기준 390px, 라이트/다크/큰 글씨/기기 안전영역 지원. 첫 화면의 핵심 결정 정보는 불필요한 세로 스크롤 이전에 확인할 수 있어야 한다. 비·주의·추천은 색상만으로 뜻을 표현하지 않는다.

### 4.2 시간별
36시간 기존 기본 표시 유지, 필터 24/48/72시간 확장은 공급자별 실제 예보 범위와 데이터 비용 검증 후 적용. 기온 추세, 강수확률, 시간당 예상 강수량, 바람·돌풍, 모형 예보 발효시각과 결측값을 구분. 강수 홈 카드를 눌렀을 때 해당 시간대에 포커스한다.

### 4.3 주간
기존 7일 예보 유지. 날별 최대/최저/대표 날씨·강수, 날짜 상세 펼치기, 기온 변동 비교. 10일 확장은 공급자 품질 검증 후 보류 해제.

### 4.4 활동 추천
생활(우산·옷차림·산책·빨래·세차)와 농업(수확·방제·관수 참고·시설물 점검) 분류. 사용자가 관심 활동을 저장하면 추천 TOP 3에 반영. 추천 시간과 근거(강수·풍속·습도·기온), 제한 사항을 노출. "살포해도 안전" 등의 단정적 농약 지시 금지.

### 4.5 전국/전문 지도
기존 주요 도시 지도와 모바일 집중모드(compact → expanded → full), 드래그 핸들·선택 팝업 유지. 지도 레이어 토글은 기온/강수/공식 특보/레이더를 출처별로 분리. 레이더는 실제 영상의 관측시각·재생시각·범례·출처·지연을 보여주고, 강수 예측과 혼합해 "실시간"이라고 부르지 않는다. 전문 모델 비교는 별도 펼침 메뉴.

### 4.6 지역 관리 및 동시 비교
국내 법정동 데이터 기반 자동완성과 GPS 역지오코딩 보존. 저장 지역 최대 10개(별칭·삭제 취소·순서 변경). "현재 위치 vs 목적지" 같은 시각 또는 사용자가 정한 날짜·시간의 기온/강수/바람·특보를 나란히 비교하며 날짜·시간대를 동일하게 맞춘다. 대표 좌표로 조회한 날씨는 정확한 건물 주소의 현장기온으로 표시하지 않는다.

**임계값 구분:** 홈 12시간 강수 판단의 50%/0.3mm와 기존 Android 맞춤 비 알림의 사용자 선택 기본 65%/1.0mm는 다른 목적의 조건이다. 임의 통일하지 말고 각각 설정 버전과 단위 테스트를 유지한다. 모델 해설의 강수 변화 이벤트 55%/0.3mm도 별도 규칙이다.

**WH-H03-v1 옷차림·우산 규칙:** 현재 모델 체감온도를 `≤-10 / ≤0 / ≤8 / ≤15 / ≤21 / ≤27 / <33 / ≥33°C` 구간으로 나눠 보온 외투부터 통풍되는 옷까지 안내한다. 앞으로 6시간의 최대 풍속 25km/h 이상 또는 최대 돌풍 35km/h 이상이면 바람막이를 덧붙인다. 우산은 WH-H01과 동일한 향후 12시간 `강수확률 50% 이상 또는 시간당 강수량 0.3mm 이상` 신호를 사용한다. 체감온도나 강수값이 없으면 해당 추천을 생성하지 않고 자료 부족을 표시하며, 모든 문구는 모델 예보 기반 참고 안내와 개인차를 함께 밝힌다.

**WH-P02-RISK-v1 근거 범위:** 벼 활착·감수분열기의 17°C 이하 저온 참고는 [농사로 현장기술지원](https://nongsaro.go.kr/portal/ps/psz/psza/contentSub.ps?cntntsNo=207427&menuId=PS00077), 벼 감수분열기 38°C·출수/개화기 35°C 이상 고온 참고는 [농촌진흥청·충남도농업기술원 안내](https://rda.go.kr/board/board.do?boardId=farmlcltinfo&dataNo=100000812378&mode=updateCnt&prgId=day_farmlcltinfoEntry), 사과·배·포도·복숭아 개화기 저온값은 [농촌진흥청·전북특별자치도농업기술원 안내](https://www.rda.go.kr/board/board.do?boardId=farmlcltinfo&dataNo=100000802119&mode=updateCnt&prgId=day_farmlcltinfoEntry)를 연결한다. 이는 모델 2m 기온을 이용한 사전 확인 신호이며 농장 미기상·품종·지형을 반영한 피해 확정값이 아니다. 근거가 없는 단계에는 작물 전용 임계값을 만들지 않는다.

### 5.1 화면 재활성화 카드의 세부 결론

- 우선순위는 **홈 위젯 → 알림 안정화 → 선택형 화면 켤 때 날씨**.
- Android 기본 제공 잠금화면을 교체하지 않는다. 제안하는 것은 기기 정책이 허용하는 범위에서 잠금 해제 뒤 짧게 표시되는 날씨 미리보기 또는 사용자가 실행하는 미리보기다.
- 기본 OFF. 앱 설정에서 기능 설명/미리보기를 본 뒤 명시적으로 활성화. 표시에 OS 오버레이 권한이 필요한 방식이면 그 시점에만 SYSTEM_ALERT_WINDOW 승인 화면을 요청. 거부 시 기존 위젯·알림 그대로 사용.
- 제안 기본값: 잠금 해제 이후, 5초 표시, 30분 쿨다운, 닫기 및 자세히 보기, 앱 설정에서 언제든 OFF. 설정값 선택지는 3/5/10초/직접 닫기, 매번/15/30/60분으로 제안.
- 앱·잠금화면·타 앱 입력·보안/결제/통화/긴급 UI를 가리지 않는다. 잠긴 화면 위 광고·배너·전면광고·구독 유도 표시 금지. 앱의 정상 본문 밖 광고도 표시하지 않는다.
- ACTION_SCREEN_ON은 동적 등록 수신이 필요하고 Android 버전에 따라 앱이 종료되면 전달/배경 실행이 제약된다. ACTION_USER_PRESENT도 항상 실행 보장이 아니다. 권한만으로 화면 켤 때마다 오버레이가 반드시 열리는 것은 아니다. 강제 부팅·과도한 상주 서비스·배터리 최적화 해제 요구는 하지 않는다.
- Android 14 에뮬레이터에서는 앱 프로세스가 살아 있으면 강제 deep idle 중에도 화면 OFF 제거와 화면 재활성화 표시가 동작했다. 재부팅 뒤 설정·스냅샷·권한은 유지됐지만 프로세스가 종료된 상태에서는 화면 ON만으로 앱이나 카드를 강제 시작하지 않았고, 앱을 다시 연 뒤 동적 수신기가 복구됐다. 이 결과를 다른 OS·제조사 보장으로 확대하지 않는다.
- 기기/OS별 구현 검증에서 백그라운드 실행 제약이나 심사 위험이 높으면 기능 플래그를 OFF 유지하고 **홈 위젯+알림**으로 대체한다. 지원이 증명되기 전 마케팅에 "화면을 켤 때 무조건 표시"라고 주장하지 않는다.

### 5.2 위젯 갱신 정책
- Android 네이티브 AppWidgetProvider 또는 Glance 사용. WebView DOM을 캡처해 위젯으로 표시하지 않는다.
- 메인/위젯/알림이 동일한 정규화 날씨 저장소를 공유하고, 화면별로 동일 출처·관측시각/예보유효시각을 표시한다.
- 위젯은 시스템 주기 갱신 최소 30분 제약을 따르며, 배터리 절약 기본은 60분 제안. 수동 새로고침·앱 진입 후 갱신은 별도 지원하고 연타는 제한한다.
- 데이터 조회 실패 시 마지막 데이터에 "저장값/오래됨" 표시; 값이 없다면 "날씨 정보 없음". 다른 지역이나 오래된 기온을 최신 상태로 위장하지 않는다.
- 위젯 누름: 메인/시간별/지역 관리 등 정확한 화면으로 이동. 위젯 추가 시 사용자별 지역 선택 지원.

**WebView 공유 구조**
- 웹(softm/weatherhannun): UI, 지역 관리, 브리핑, 판단 규칙, 기간별 예보, 활동 추천, 전문 지도.

**데이터 흐름**
사용자 GPS/법정동 선택 → 지역 대표좌표 또는 GPS 격자 정규화 → 공급자 어댑터/캐시 → 공통 날씨 데이터 계약 → 12h 강수/어제 비교/옷차림/브리핑/활동 추천 → 오늘·시간별·주간·지도/위젯/알림.

현재 API는 무료 Open-Meteo 예보·대기질 모델을 클라이언트에서 직접 호출한다. 정식 수익화 전에 다음을 수행한다.
1. Open-Meteo 상업용 API 계약 또는 개별 이용허락이 확인된 기상청·에어코리아 등으로 **예보/공기질/역지오코딩/지도·레이더 모두** 전환하거나 적법한 사용권을 증빙.
2. 공개 GitHub Pages JavaScript에 API 비밀키를 넣지 않는다. GitHub Actions + GitHub Secrets의 지역·격자 단위 공개 정적 캐시와, 실시간 GPS/임의 좌표 요청이 필요한 경우의 **날씨 데이터 전용 최소 API 게이트웨이**를 분리한다. 게이트웨이는 프런트엔드 호스팅 변경이 아니며 Vercel 사용은 금지한다.
3. 캐시 키는 공급자/격자/자료 유형/예보 기준시각으로 나누고 TTL은 **공급자 실제 갱신주기 기반**으로 확정. 과도한 전국 19,574개 동 일괄 API 호출은 하지 않는다.
4. 사용량 제한·요청 중복 제거·타임아웃·Etag/TTL·오류 fallback·예보 변경 이력·비용 감시를 구현한다.
5. 현재 Nominatim 역지오코딩의 공개 서버 호출/호출 제한은 별도 이용조건을 점검하고 사업 확장 전 허가된 공급자로 바꾼다.

| 위치 | locationId, name, regionType, lat, lon, nx, ny | GPS·행정구역 중심 분리 |
| 출처 | provider, product, licenseId, kind | observation/forecast/warning/air/radar 구분 |
| 시각 | observedAt, issuedAt, validAt, fetchedAt | 각각 관측/발표/예보 유효/API 읽기 시각 |
| 기상 | temperature, feelsLike, pop, precipitationMm, wind, gust, humidity | 각 단위·관측/모델 표시 |
| 상태 | freshness, cached, missingFields, fallbackReason | 오래됨/조회 오류/결측 구분 |
| 판단 | decisionType, evidence, recommendation, uncertainty | 근거와 한계, 룰 버전 기록 |

**데이터 품질 규칙**
- 관측 시각이 없는 모델값은 실측으로 표현하지 않는다. 공식 특보는 독립 채널과 출처 원문을 붙인다.
- 어제 비교는 기본적으로 동일 종류의 동일시각 관측-관측 비교. 부족하면 수치를 만들지 않고 "어제 관측 비교 준비 중" 상태를 표시한다.
- 공식 센서 관측소와 행정구역 중심점 거리가 크거나 고도·지형이 다르면 "인근 관측소"라고 표시한다.
- 누락된 확률/강수/기온을 0으로 대체하지 않는다. 12h 비 카드의 "신호 낮음"은 비가 절대 오지 않는다는 보증이 아니다.
- 오래된 저장 예보(현 코드 조회 후 180분 초과)는 재조회 필요 표기. 긴급 특보 데이터가 오래되면 신뢰하기 어려운 상태로 표시하고 공식 원문 확인 경로를 제공한다.

## 7. 수익화 설계와 앱 광고 위치

### 7.1 단계별 모델

| 단계 | 수익원 | 무료 유지 | 도입 조건 |
| --- | --- | --- | --- |
| 1 | AdMob 또는 Kakao AdFit | 현재/시간별/주간/특보/필수 알림 | 상업적 데이터 이용권, 개별 앱 광고 ID, 동의·Play 정보 완료 |
| 2 | Plus 구독 후보 | 필수 날씨·안전 알림 | 광고 제거, 위젯 테마, 고급 활동 알림·개인화 가치 확인 후 실험 |
| 2 | 농업 Premium 후보 | 기본 농작업 위험 참고 | 여러 필지·작물/생육단계·반복 계획·위험 리포트 검증 |
| 3 | 기관·사업자 | 개인 서비스 무료 가치 | 다중 현장·팀 리포트·관리/내보내기·계약형 가격 |

가격은 **확정하지 않는다**. 가격, 무료 체험, 연간 할인, 상품 묶음은 추후 A/B 실험/Play Billing 정책 검토로 결정한다. 구독자는 구매 복원·해지/만료·동기화와 광고 제거를 명확히 제공한다. 공식 위험기상 경고는 유료 전용으로 잠그지 않는다.

### 7.2 광고 규칙
- Android의 **독립된 하단 접힘형 슬롯 1개**. AdMob 우선 또는 AdFit 대체이며 동시에 2개 이상 요청/노출하지 않는다.
- 키보드/작은 화면/화면 재활성화 카드/잠금 상태/유료 광고제거 고객/광고 실패에는 광고 슬롯 없음.
- 앱 시작 직후·종료 직전·메뉴 클릭 직후 끼워넣는 전면광고를 기본 적용하지 않는다. 위험 경고, 우산 카드, 주요 터치 버튼을 광고로 가리지 않는다.
- 앱 이름으로 새 광고 단위 ID 발급. 다른 한눈 앱 ID를 재사용하지 않는다. UMP 동의 및 데이터 안전/개인정보 안내 확인.
- Release 광고 차단 플래그와 설정은 Android docs/ADS.md가 구현 기준. 문서 작성만으로 해제하지 않는다.

### 7.3 광고 매출 가정과 순이익

월 광고매출(원) = DAU × 일 세션 수 × 세션당 **유효 노출** × 30 × eCPM ÷ 1,000.

| 가정 DAU | 2세션/일, 1.2유효 노출/세션, eCPM 2,000원 시 월 광고매출 |
| ---: | ---: |
| 1,000 | 144,000원 |
| 5,000 | **720,000원** |
| 10,000 | 1,440,000원 |

이 수치는 실제 광고 단가나 경쟁사의 매출이 아니라 **수식 예시**. 순이익 = 광고매출 + 구독매출 - 데이터 라이선스 - 서버/트래픽 - 결제/광고 플랫폼 수수료 - 운영/지원/개발비. DAU 5,000에서도 데이터 비용이 과도하면 손해일 수 있으므로 지역별·일별 API 원가를 모니터링한다.
