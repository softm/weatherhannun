수집 주기 및 근거

데이터 조회사용자가 접속하거나 지역을 바꿀 때 브라우저에서 직접 실시간 요청
재조회새로고침 버튼을 눌렀을 때 수동 재조회 · 백그라운드 크론 없음
이전 데이터 표시마지막 성공 예보를 브라우저에 저장하고 통신 오류 때 참고 표시
기상 데이터Open-Meteo Forecast API (모델 기반 예보)
대기질 데이터Open-Meteo Air Quality API (실측이 아닌 모델 예측)
위치정보허용 시 브라우저 위치 API 사용 · 위치를 외부 계정 서버에 별도 저장하지 않음
예보 시각기상 모델 출력 시각과 실제 API 조회 시각은 다를 수 있습니다.

이용·운영 주의사항

Open-Meteo 비상업 무료 API로 실험 중입니다. 광고·유료 서비스 운영 시 상업용 계약 또는 다른 적법한 데이터 소스로 전환해야 합니다. 활동 점수는 독자 규칙의 참고 지표이며 공식 예보·특보를 대체하지 않습니다.
